# Vestra v0.1.0 — public engineering release

Vestra v0.1.0 is the first public, reproducible release of the three-repository
Vestra system: a local-first Rust video-to-world product, a native DA3
inference engine, and independently qualified fixed-shape kernels.

## Try the frozen public scene

From a clone of `hoppworks/vestra` at this tag:

```bash
./scripts/run-public-demo.sh
```

The launcher downloads the 380 MB scene archive, verifies its recorded
SHA-256, extracts it, and starts Vestra Studio on loopback. It downloads no
model and performs no inference. The scene contains the original browser-ready
input, immutable local measurements, a local TSDF product, and a separately
labelled COLMAP dense-MVS control.

## What is qualified

- A six-command product surface is separated from 28 explicit lab and oracle
  commands.
- Fresh public clones resolve exact Vestra Engine and Vestra Kernels commits.
- The local verification gate covers formatting, strict Clippy, 138 Rust
  tests, 26 Python tests, browser-control tests, documentation links, and the
  locked dependency graph.
- Numerical parity precedes each performance claim. On the locked Ryzen 9
  9950X CPU study, the DA3-BASE single-image F32 slice measured 171.141 ms in
  Rust and 238.789 ms in C++ (28.3% lower latency, N=20).

## Public fixture

The release fixture is the CC-BY-4.0 TUM RGB-D `freiburg1_room` RGB sequence.
The reconstruction did not consume the dataset's ground-truth camera poses.
The frozen run retained 363 input candidates, 77 geometry frames, nine
measured windows, 4,275,936 local measured points, and a 40,980-point local
TSDF product. The optional pinned COLMAP branch contributes a separately
attributed 355,581-point dense-MVS control linked to 55 selected cameras.

See the [validation record](https://github.com/hoppworks/vestra/blob/v0.1.0/docs/validation/PUBLIC_DEMO_FREIBURG1_ROOM_2026-08-20.md),
[machine-readable manifest](https://github.com/hoppworks/vestra/blob/v0.1.0/demo/release.json),
and [attribution notice](https://github.com/hoppworks/vestra/blob/v0.1.0/demo/ATTRIBUTION.md).

## Boundaries

The accepted product is relative-scale. The release does not claim a semantic
or watertight mesh, guaranteed global coherence for arbitrary captures, a
device-resident CUDA pipeline, or pure-Rust ownership of the optional COLMAP
derivative. Those boundaries remain visible in the scene and documentation.
